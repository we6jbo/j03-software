# cowlesrun v0.2.0
Qt 6 Widgets desktop calculator for the arithmetic mean of up to four Cowles Mountain summit times. Enter MM:SS or HH:MM:SS. Blank entries are excluded. Displays the mean rounded to the nearest second. Data is not saved or sent across a network.

The upper-left original AI-generated illustration is *inspired by* the Killdeer Mountains, North Dakota. It is not a documentary photograph of the location. The source image is embedded in the binary as a Qt resource.

`cmake -S . -B build && cmake --build build -j2 && ./build/cowlesrun`

Identifiers: TG415161, TG171824, TG859743, TG907216. They appear in source/About/tg_context_snapshot.json. The local registry is optional.
