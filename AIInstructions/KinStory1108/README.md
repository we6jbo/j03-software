## Build requirements

The application was developed using C++17, Qt 6 Widgets, and CMake.

This public export contains development reference material rather than
a complete, independently buildable application.

The original application depends on function_classified.txt, which
contains private and unconfirmed genealogical research data and is
intentionally excluded from this public export.

To build a functional version, a developer must provide a compatible
ConnEntry data structure and kConnections array through
function_classified.txt.

Do not publish private genealogy records, protected birth years,
or unverified family relationships.

The original application was designed for November 7–8, 2026.
